# Problem: Reverse String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

## Approach

The string is reversed using the two-pointer technique. One pointer starts from the beginning and another starts from the end. The characters at these positions are swapped, and the pointers move toward the center until the entire string is reversed.

## Complexity

- Time: O(n)
- Space: O(1)
